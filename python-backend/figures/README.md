# figures/: 図のサービス（2 層目）

設計書 `docs/figure-design.md` の第 1 節と第 5 節の実装です。図の宣言を受けて 1 枚の絵を返し、読む要求に読む点を返します。答え（中央値、Δ）は作りません。1 層目の演算（`services/combine_ops.py`）を、`answers.py` のインターフェースを通して呼びます。

製品の画面に載っているのは、比較台のすべての図です（線の重ね図と Δ、帯域の棒、時間信号、熱図、トリガーのイベントとその下の段。一覧は [docs/figure-list.md](../../docs/figure-list.md)）。分布図（`bins`）は入口の分布図として載っています（値が表の列（CSV の数の列）のとき）。種類の足し方は [docs/figure-kinds-guide.md](../../docs/figure-kinds-guide.md) にあります。

## ファイルと 5 種類の計算

| ファイル | 計算 | 関数 | 受け取るもの | 返すもの |
|---|---|---|---|---|
| `members.py` | ア 載せるものを決めて数える | `members` | 図の宣言（鍵ごとの状態と版）、答えの単位・基準・軸と版 | 載せる集まり（`shown`）、中央値・Δ に使う集まり（`combined`）、線ごとの使う鍵と使わない鍵と理由、件数、校正の言葉 |
| `ranges.py` | イ 確定範囲 | `confirmed_range` | 線の答え（間引く前）、量、Δ かどうか、軸の端、指定範囲 | 確定範囲 |
| `thinning.py` | ウ 描く用の点 | `drawn_line` | 線の答え、確定範囲、枠の幅 | `Drawn`（描く用の点） |
| `pick.py` | エ 読む点 | `pick` | 段のすべての線の答え、確定範囲、ポインターと縮尺／点の番号と方向／点の名前 | 点の名前（1 点だけ。前後の点は返さない）、または「値なし」「線の外」「点がない」 |
| `headline.py` | オ 見出しに出す点 | `delta_peak` | Δ の答え、確定範囲 | 点の名前（読み値と同じ形） |

numpy を使えるのは、この 5 つのファイルだけです（決まり A）。

### 図の種類ごとの関数

段の種類（宣言の `kind`）ごとに、同じ 5 つのファイルの中へ関数を足します。計算の種類は増やしません。

| 段の種類 | 答えの型（`answers.py`） | イ | ウ | エ |
|---|---|---|---|---|
| `lines`（スペクトルの重ね描き） | `Answer` | `confirmed_range` | `drawn_line` | `pick` |
| `image`（スペクトログラム、粗さ、ケプストログラム。1 段に 1 つの録音。同じ図の `image` の段は、横、縦、色の範囲をそろえる） | `ImageAnswer`（行の軸と量から、対数か線形か、まとめ方が決まる） | `image_axes`、`image_extent`、`image_colour`（色の範囲。レベルは `colour_range`、ケプストログラムは 0 を中心に対称、粗さは最小から最大） | `drawn_image`（セルと、その境界＝配置。まとめるセルの中の最大。符号つきは絶対値が最大の値） | `pick_cell` |
| `band`（時間信号。録音ごとに 1 本。中央値は取らない） | `SignalAnswer`（標本と、開始時刻、標本化周波数。時刻の配列は持たない） | `band_range`（横は標本の端から端、縦は画面内の標本の最大の絶対値から） | `drawn_band`（2 px に 1 区画、区画ごとの最小と最大の標本。それぞれの標本の時刻に置く） | `pick_sample` |
| `bins`（分布図。群ごとに 1 段。利用者の表の数の列だけ） | `ColumnAnswer`（列の鍵と版、行の鍵、行ごとの値。空欄は NaN） | `value_axis`（値の軸。全部の段で 1 つ）、`count_axis`（件数の軸）、`bins_range` | 配置：`bin_edges`（48 区間の境界）、`bin_of`（行が入る区間）、`stacked_levels`（点の段） | `pick`（`bin_lines` が棒、行、役割の線を読む線に直す）、`bin_under`（点がない場所の区間） |

熱図で「画面に入っているセル」は、セルの一部でも確定範囲に入っているセルです（`thinning.py` の `cells_on_screen`）。描くセル、読むセル、矢印キーで進めるセル、色の範囲は、この 1 つの規則で決めます（範囲の端で切れるセルも描き、読めます）。熱図の描く用のセルは、時間は 2 px に 1 列まで、周波数は 2 px に 1 行までならそのまま、それより細かければ対数の帯域にまとめます。まとめ方は最大です（レベルと粗さは最大、符号のある量は絶対値が最大のもの。短い出来事を薄めない）。描くセルは、いつも答えのセルのどれか 1 つの値です。周波数の点が 1 つも入らない帯域は、その帯域の中心が入っている答えのセルの値にします（2 つのセルの間を補間した値は作りません）。読むセルと色の範囲は、まとめる前の答えのセルから決めます（描く用のセルからは決めません）。

時間信号は 30 分の録音（48 kHz で 8,640 万標本）でも、標本を写しません。帯は標本が置かれた場所をそのまま 2 つの表として見て作ります。読み値はポインターに近い標本から外へ順に見て、それより近い標本がありえなくなったところで止めます。Figure は標本を取り置きません。読む要求のたびに鍵で答えを引き直し、答えがもう無ければ「絵がない」と答えます（Figure が描き直します）。

分布図は、5 種類の計算を ア（載せる行）、イ（値の軸）、配置（区間の境界と点の段）、ア（区間ごとの件数）、イ（件数の軸）の順に呼びます（設計書 第 1 節）。件数は `members.py` の `rows_shown`、`rows_picked`、`bin_counts` が数えます。区間と選んだ範囲は、下の端を含み上の端を含みません（軸のいちばん上の端だけ含む）。だから、選んだ区間が取る行は、その棒が数えた行とちょうど同じです。行が 12 未満の群は、棒ではなく点で描きます。基準群の中央値の線は描きません（仕様 7）。役割を持つ行（基準、比較 1…）だけを線で描きます。

表の列は、宣言の中では鍵と版で名指しします。値は、その鍵を初めて名指す要求（draw、export、count）の `columns` に 1 回だけ載って届き、`services/answer_store.py` の `COLUMNS` が、自分の上限（バイト数）の中で取り置きます。取り置きに無い列は、絵の中で「載せなかったもの」（`evicted` または `version`）に数え、画面の側が列を付けて 1 回だけ出し直します。

## ほかのファイル

| ファイル | すること |
|---|---|
| `picture.py` | 絵を組み立てる。算術をしない。`Drawn` を受け取れる唯一のファイル（決まり B）。`thinning.py` を呼び、`Drawn.wire_points` で点を取り出す |
| `service.py` | 5 種類の要求（draw、read、export、release、count）。鍵で答えを引き、ア、1 層目、イ、オ、絵の順に呼ぶ。Figure の id ごとに、いちばん新しい世代の結果だけを取り置く。計算はしない |
| `answers.py` | 「鍵で答えを引く」インターフェース（`AnswerSource`）と 1 層目の演算のインターフェース（`LayerOne`）。実物は `transport/figure_answers.py` が渡す |
| `spec.py` | 図の宣言をデータとして読む。計算はしない |
| `budget.py` | プロセス全体で 1 つの予算と、計算の前の取り分け（設計書 第 5 節）。答えの保持、Figure の取り置き、いま走っている要求の取り分けを合わせて数える。単独で超える要求は「大きすぎる」、ほかの要求と並ぶと入らない要求は「混んでいる」（Figure が少し待って 1 回だけ出し直す）。入らないときは、どの Figure も使っていない答えを先に手放し、次にいちばん長く読まれていない Figure の取り置きを手放す。実物の予算は `transport/figure_answers.py` の `BUDGET` |

## 守ること

- `figures/` が import してよいのは、標準ライブラリ、`figures`、`frames`（Frame の読み方）、wandas、wandas-extras だけです。numpy は 5 つの規則のファイル（`members.py`、`ranges.py`、`thinning.py`、`pick.py`、`headline.py`）だけが使えます。`services/`、`transport/`、入口は import しません。`scripts/check_figure_imports.py` が verify の中で確かめます。
- `Drawn` と `DrawnImage` の名前が出てよいのは `thinning.py` と `picture.py` だけです（同じ検査）。範囲、読む点、見出し、件数の関数は `Drawn` を受け取りません。
- 第 1 節の 5 種類のほかの計算（平均、中央値、差、dB への変換など）を、ここに書きません。要るときは 1 層目に足します。

## テスト

- `test_figures_service.py`：答えの分かっている信号での絵、読み値、確定範囲、件数、取り置き、id。最後は本物の経路（wandas のスペクトル、`stage_combine.STORE`、`command_dispatch`、プロトコルの型）。
- `test_figures_pick.py`：共有のテストデータ `pick_cases.json` と `figure_overlay_cases.json` の R7 を `pick` で再生する。仕様 1 で変わった 2 件は、テストの中に古い答えと新しい答えを並べて書いてある。
- `test_figure_imports.py`：import と `Drawn` の検査が通ること、わざと誤りを入れると落ちること。
- `test_figures_heatmap.py`：古い経路から記録した `figure_heatmap_cases.json` を、熱図の関数（列の区切り、まとめ方（最大）、帯域、拡大した絵、色の範囲、セルの境界、本物の Frame の読み値）とプロトコル経由の draw / read / count で再生する。古い経路と変えた点は、ファイルの先頭に書いてある。
- `test_figures_signal.py`：古い経路から記録した `figure_signal_cases.json` を、時間信号の関数（区画、区画ごとの最小と最大、全体と拡大の帯、振幅の軸、標本の読み値）とプロトコル経由の draw / read / count で再生する。標本を直接読む読み値が、同じ点を線として読んだとき（`pick`）と同じになることも確かめる。予算と取り分け（大きすぎる、混んでいる、答えを手放す順）のテストもここにある。
- `test_figures_distribution.py`：古い経路から記録した `figure_distribution_cases.json` の配置、読み値、範囲の選択を、プロトコル経由の draw / read で再生する。古い経路と変えた点（区間の端の規則、基準群の中央値の線、空欄の件数）は、ファイルの先頭と、テストの中の古い答えと新しい答えの並びに書いてある。選んだ区間が取る行と棒の件数が同じになることを、乱数の 200 通りで確かめる。列を 1 回だけ渡すこと、無い列と版の違う列の扱いもここにある。

## ほかの図と目盛りをそろえる（`scaleWith`）

Tracks の録音の行は、チャンネルごとに 1 つの図です。「スケールを連動」を入れると、行の宣言の段（`band` と `image`）が、ほかの行の答えの鍵を `scaleWith` に並べます。図のサービスは、その中から自分と同じ単位と基準の答えだけを取り、波形は全部の録音の全サンプルの最大から、スペクトログラムは全部の録音のレベルの最小と最大から、自動の範囲を決めます（`ranges.shared_amplitude`、`ranges.image_colour`）。画面は鍵を並べるだけで、単位の見分けも範囲の計算もしません。取り置かれていない答えは数に入れません。決まりのテストは `python-backend/test_tracks_linked_scales.py` です。
